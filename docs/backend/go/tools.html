Go 工具

Go 工具链简洁但强大，日常开发离不开 go 命令和相关辅助工具。

常用命令​

go mod init
go mod tidy
go run .
go build
go test ./...
go fmt ./...
go vet ./...

常用工具​

  • gofmt：格式化；
  • go test：测试；
  • go vet：静态检查；
  • pprof：性能分析；
  • dlv：调试；
  • golangci-lint：综合 lint。

建议​

把格式化、测试和静态检查加入 CI，减少人工遗漏。
