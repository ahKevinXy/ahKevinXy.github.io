最新 JetBrains 全家桶激活：PhpStorm、GoLand 授权教程

2026年11月3日 · 阅读需 10 分钟
ahKevinXy
作者

使用 PHP、Go 或多个技术栈开发时，常会遇到 PhpStorm 激活、GoLand 激活和 JetBrains 全家桶激活的问题。本文整理各产品的授权入口、JetBrains Account 登录与离线激活方法，先介绍 ckey.run 原文资源与通用激活码的使用流程，再说明全家桶订阅的适用范围。

原文资源与通用激活码：使用教程​

原文资源入口：ckey.run。该第三方站点提供操作指南和产品代码生成入口；其中的通用产品条目与官方 All Products Pack 订阅是不同的概念。

1. 打开入口，选择需要的操作​

进入站点后，可以搜索 PhpStorm、GoLand 或插件名称，再查看相应产品卡片。页面的“激活指南”按操作系统提供说明，并区分激活、调试、取消激活、离线及帮助入口。

  • 使用网站生成的内容：找到产品卡片，点击“生成并复制”。
  • 使用旧文保留的内容：打开旧文激活码记录，使用代码块的复制按钮。
  • 采用该站脚本方式：先查看“激活指南”中对应系统与操作的说明。

2. 查看 Windows、Linux、macOS 对应命令​

下面是该站“激活”页当前展示的命令，供对照使用。本文核对了网页说明，未执行这些远程脚本或验证激活效果。复制代码与运行脚本是不同的操作，具体前提和顺序以该站说明为准。

Windows： 该站说明为按 Win + X 打开管理员 PowerShell，运行：

irm ckey.run|iex

Linux： 在终端下载并运行脚本：

wget -q ckey.run -O ckey.run && bash ckey.run

macOS： 在终端下载并运行脚本：

curl -Ls ckey.run -o ckey.run && bash ckey.run

需要排障、取消先前配置或离线使用时，应查看网站对应标签下的说明；上面列的是“激活”操作，不应混作其他操作命令。原站激活指南与帮助

3. 复制 PhpStorm、GoLand 或通用条目的代码​

使用场景在网站上选择复制后到哪里填写
PhpStorm 激活搜索并选择 PhpStorm 产品卡片PhpStorm 的许可管理窗口 → Activation code
GoLand 激活搜索并选择 GoLand 产品卡片GoLand 的许可管理窗口 → Activation code
原站通用条目选择 All Jetbrains's Product Or Plugin对应 IDE 或插件的代码输入入口，实际适用范围以反馈为准

操作顺序：复制完整代码 → 打开 IDE 许可管理窗口 → 选择 Activation code → 粘贴 → 点击 Activate → 查看处理结果。

PhpStorm 可从 Help → Manage Subscriptions 进入；GoLand 可从 Help → Register 进入。不同版本可能显示其他许可管理名称，可继续阅读下方 PhpStorm 步骤和GoLand 步骤。

复制代码时，不要把 Markdown 的三个反引号、代码语言标记或其他说明文字一起粘贴。执行命令结束或复制完成，都不等于 IDE 已接受代码，应回到许可窗口确认反馈。

4. 使用旧文保留的通用激活码​

原有代码继续保留在JetBrains 全家桶激活旧文中，本篇提供使用流程，避免重复粘贴长代码。打开旧文后，复制完整代码，再回到对应 IDE 的 Activation code 输入框操作。

旧文代码没有经过当前可用性、版本兼容性或有效期验证；需要原站当前生成的内容时，可使用产品卡片的复制入口。

5. 常见问题与检查顺序​

现象检查方法
提示 Key is invalid先核对产品与复制内容；该站帮助还建议，曾使用其他工具时，先用原工具取消其配置并重启，再按指南处理
远程开发未生效该站要求本地与远程 IDE 版本保持一致，先核对两端版本
页面没有复制成功重新使用产品卡片或本文代码块的复制按钮，确认内容完整
IDE 更新后代码被拒绝核对实际版本与网站当前说明；本文没有已验证的完整兼容版本表

以上是原站使用方式与问题说明；账号授权和第三方产品代码的来源不同，可按下面章节分别核对。

JetBrains 全家桶包含哪些工具​

“JetBrains 全家桶”通常指 All Products Pack，可在一份订阅下使用多款开发工具，包括 PhpStorm、GoLand、IntelliJ IDEA、PyCharm、WebStorm、Rider、CLion、DataGrip、RubyMine 和 RustRover。具体权益以订阅页面和账号中显示的许可为准。All Products Pack 官方介绍

工具主要开发场景下载与激活说明
PhpStormPHP、Laravel、Symfony、WordPress 等项目官网下载 · PhpStorm 激活步骤
GoLandGo 项目开发官网下载 · GoLand 激活步骤
IntelliJ IDEAJava、Kotlin 等 JVM 项目产品介绍
PyCharmPython 项目产品介绍
WebStormJavaScript、TypeScript 与前端项目产品介绍
DataGrip数据库与 SQL 开发产品介绍

只需要一款 IDE 时，可以核对对应产品的许可；使用多款 IDE 时，再比较 All Products Pack 的覆盖范围。IDE 授权与第三方付费插件的授权需要分别确认，不能仅凭“全家桶”名称判断某个插件已经包含。

PhpStorm 激活教程​

PhpStorm 支持通过 JetBrains Account、激活码以及组织提供的许可证服务进行授权。已有单独的 PhpStorm 许可或包含该产品的 All Products Pack 订阅时，可以按以下流程操作。

使用 JetBrains Account 激活 PhpStorm​

  1. 从官网下载并启动 PhpStorm。
  2. 在主菜单打开 Help → Manage Subscriptions；欢迎界面也可通过选项菜单进入 Manage Licenses。旧版本可能显示 Help → Register。
  3. 选择账号登录，在浏览器中完成 JetBrains Account 登录并返回 IDE。
  4. 选择覆盖 PhpStorm 的有效许可，点击 Activate。
  5. 如果列表尚未更新，点击 Refresh license list，再核对账号和订阅状态。

离线环境可以在许可支持的情况下，使用从本人 JetBrains Account 获取的离线激活码；组织统一分配许可时，使用管理员提供的 Floating License Server 或 License Vault 配置。PhpStorm 官方激活文档

GoLand 激活教程​

GoLand 的账号激活入口与 PhpStorm 类似，但需要核对当前许可是否覆盖 GoLand，不能把其他单款 IDE 的许可直接视为 GoLand 授权。

  1. 从官网下载并启动 GoLand。
  2. 打开 Help → Register，进入订阅管理对话框。
  3. 使用持有 GoLand 许可或 All Products Pack 订阅的 JetBrains Account 登录。
  4. 选择有效许可并点击 Activate；未显示时刷新许可列表。

需要离线激活时，在账号中检查可下载的激活码；企业环境按管理员提供的许可证服务配置。浏览器完成登录后 IDE 未收到回调时，可以查看对话框的 Troubles? 入口，按界面提示使用授权令牌登录。GoLand 官方激活文档

JetBrains 全家桶如何激活​

持有 All Products Pack 订阅后，可以在覆盖的不同 IDE 中使用同一个 JetBrains Account 获取许可。例如，先在 PhpStorm 中完成账号激活，再在 GoLand 中登录同一账号，分别选择账号提供的有效授权。

Toolbox App 可用于安装和管理多个 JetBrains IDE；已在 Toolbox 中登录账号时，相关 IDE 可以自动关联账号。安装工具与许可是否有效仍需分别核对。账号激活说明

全家桶订阅的到期时间、可用产品和其他权益以账号记录为准。不要把某个第三方插件的激活状态等同于整个 IDE 或全家桶的授权状态。

试用、教育授权与非商业许可的区别​

方式适合核对的情况需要确认的事项
官方试用安装后评估 PhpStorm 或 GoLand官方文档提供最长 30 天试用；试用不等于长期授权
单产品订阅主要使用 PhpStorm 或 GoLand 中的一款许可覆盖的具体产品、有效期和版本
All Products Pack同时使用多款 JetBrains IDE账号中的订阅权益及各产品覆盖范围
教育授权符合条件的学生、教师申请资格、有效期及用途限制，见学生计划与教师计划
开源项目支持符合条件的开源项目维护者项目资格及申请要求，见开源支持计划

PhpStorm、GoLand 可以免费激活吗？​

可以先核对官方试用及本人符合条件的免费授权计划。JetBrains 当前官方通用非商业免费许可 FAQ 列出的产品包括 CLion、Rider、RubyMine、RustRover、WebStorm 和 DataGrip，没有列入 PhpStorm、GoLand，因此不能把其他产品的免费规则直接套用到这两款 IDE。非商业许可官方 FAQ

教育授权、开源项目支持和非商业免费许可是不同的计划，应分别核对适用条件。

离线激活码从哪里获取？​

已有支持离线激活的许可时，登录 JetBrains Account，查看对应许可可用的激活码，再在 IDE 的激活对话框中使用。能否离线激活取决于许可类型；例如官方非商业免费许可只能通过账号激活，不提供离线激活码。离线使用说明 · 非商业许可说明

订阅到期后还能使用吗？​

符合条件的年度订阅，或连续订阅达到规定期限的月度订阅，可能具有 perpetual fallback license（永久回退许可证）。它允许继续使用特定版本，具体可用版本以账号中显示的信息为准；不能把回退许可理解为所有未来版本均可持续更新。All Products Pack 官方常见问题

PhpStorm、GoLand 激活失败怎么排查​

现象优先检查
登录后没有可用许可是否登录了持有许可的账号，组织是否已分配许可，产品是否在授权范围内
刚购买或分配的许可没有显示刷新许可列表，重新核对账号中的订阅记录
激活码无效是否对应当前产品和可用版本，许可是否有效，复制内容是否完整
浏览器已登录但 IDE 没有响应查看 IDE 提供的登录排障或授权令牌入口
无法连接账号或许可证服务检查网络与代理设置；企业环境联系管理员核对访问配置
IDE 已激活但插件仍提示付费单独核对该插件的许可及分配状态

排障入口：PhpStorm 账号与许可说明 · GoLand 登录问题排查。
