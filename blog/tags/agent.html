Agent 工程师实战教程 用 Python 构建可测试的工单助手

2026年11月3日 · 阅读需 40 分钟
ahKevinXy
作者

学完 Agent 的基本概念后，最适合做的练习，是亲手完成一条有业务结果、也有明确边界的任务链路。

这篇教程实现一个工单助手：用户询问报销申请为何待补材料，助手查询本人申请、检索可访问的制度，解释原因；用户要求申诉时，助手准备草稿，由用户查看并确认后，应用创建工单。我们会把模型决策、工具执行和业务写入分别实现，再用测试检查它们如何协作。

项目使用 Python 和 SQLite，业务代码只依赖标准库。你可以先用不联网的模拟模型跑通流程，再切换到 Anthropic Messages API。文章按“做什么、写哪个文件、怎样运行、如何验收”展开，全部模块与测试直接写在正文中，可以从空目录逐步完成。

如果还没有建立学习顺序，可以先阅读Agent 开发工程师从入门到高级的学习与实战成长路线，再用本项目落实其中的模型调用、工具执行和任务验证。

Agent 开发工程师从入门到高级的学习与实战成长路线

2026年11月3日 · 阅读需 52 分钟
ahKevinXy
作者

一个能够回答问题的聊天窗口，距离一个能够可靠完成任务的 Agent 系统，还有多远？

中间隔着工具调用、数据权限、状态管理、失败恢复、效果评测，以及持续运行时的成本和维护问题。Agent 开发工程师的成长，也可以沿着这条链路展开：先理解模型如何参与程序，再让它使用工具完成有限任务，最终能够为真实业务交付可观测、可控制、可迭代的系统。

这篇文章面向准备进入 AI 应用开发的程序员，也适合已经做过聊天机器人、希望继续进阶的开发者。我们用一个逐步升级的“企业知识库与工单助手”贯穿各阶段，把学习内容对应到可以交付的项目和可以验证的能力。前半部分解释各阶段应掌握的知识，后半部分给出六周基础准备、二十四周逐周任务，以及第 25 至 52 周的高级实践安排。每个周期都列出要做的事情、交付物和验收要求，可以直接作为个人学习计划使用。

优先建立模型调用、工具执行和评测的完整闭环，再根据任务需要引入检索、持久化和多 Agent 协作。 技术栈可以更换，这些能力会持续影响项目质量。
